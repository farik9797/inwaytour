# In Way Tour — редизайн (cinematic scroll)

## Что сделано
- Собран контент со старого сайта (web.archive.org, снимок 2024-10-06): туры, преимущества, контакты, реквизиты, директор.
- Собрана одностраничная версия по промту «Mostar city» (vanilla: `index.html`, `styles.css`, `script.js`, без сборки и локальных ассетов).
- Все значения анимации/позиционирования из промта воспроизведены verbatim; контент заменён на In Way Tour (RU). Единственное отступление: кегль `.hero-title` уменьшен (`min(8.5rem, 8vw)`), т.к. «IN WAY TOUR» длиннее «MOSTAR» и не помещался между башнями.
- CloudFront не отдаёт CORS-заголовок для OggText-Medium.woff2 → браузер блокирует шрифт. Добавлена локальная копия `fonts/OggText-Medium.woff2` вторым `src` в `@font-face` (remote → local fallback).
- Добавлен блок `#contacts` под сценой (телефон, почта, часы, адрес, реквизиты, директор) — в промте его не было, но данные сайта требовали.

## Ключевые решения
- Шрифт Ogg Medium (с cloudfront) не содержит кириллицы → для русских заголовков фолбэк Playfair Display 500 (Google Fonts). Латиница «IN WAY TOUR» и цифры — в Ogg. Inter подключён с Google Fonts (кириллица для текста).
- Сценовые слои: хиро — Бали, второй кадр — Дубай (папка `img/`, WebP). Источник — Unsplash (лицензия Unsplash, коммерческое использование без атрибуции):
  - `sky.webp` — небо с кучевыми облаками над морем (photo-1773125937987);
  - `bridge.webp` (центр, «мост») — храм Пура Улун Дану Братан (photo-1544644181), удалены небо/вода/горы, кадр обрезан по шпилю, низ прозрачен ниже 74% высоты (иначе после «вылета» слой перекрывал карточки);
  - `split-left.webp` / `split-right.webp` — половинки ворот Хандара (photo-1551505256), только камень (растительность, дорога, земля удалены), на общем холсте 2000×1250 с внутренними краями на 41%/59% — при скролле ворота раскрываются;
  - `back-skyline.webp` — рисовые террасы Тегаллаланг (photo-1729814909435), верх обрезан на 30% и растушёван на 40%, бока на 320px;
  - `frame-two.webp` — Дубай (photo-1718975662468), затемнён до 0.66 и слегка размыт ради читаемости текста;
  - `glow.webp` — процедурное тёплое свечение (RGBA). Чёрный фон + `mix-blend-mode: screen` не работает, т.к. небо вне стекового контекста `.back-stack`.
  - Стамбульский вариант (мечеть/Галата/Айя-София) остался в истории git (коммит 0a610eb).
- Пайплайн вырезки: SegFormer-b2 (ADE20K) → маска классов sky/water → альфа; скрипты в scratchpad, при необходимости повторить — см. `img/` как эталон геометрии.
- `.sights-slider` поднят до `z-index: 4` (в промте 2), `.sights-controls` до 7 (в промте 5) — карточки и кнопки не перекрываются задними/боковыми слоями.
- Сплит-кадры получают `--split-opacity = 1 - sightsEnterRaw`: половинки ворот растворяются, когда приезжает слайдер (иначе висели по краям поверх карточек).
- Панель «Преимущества» (`.story-panel-bazaar`): `top: max(29%, 290px)` (мобильный `max(26%, 300px)`) — на 1280×720 и ниже она налезала на шапку (баг «Преимущества ломается»).
- CSS/JS подключены с `?v=N` для сброса кэша у посетителей; при правках стилей/скрипта увеличивать N.
- Нав «Туры»/«Преимущества» и кнопка «Подобрать тур» скроллят к нужному смещению внутри sticky-сцены через `data-scroll` (1100 / 2300 / 3700 px).
- В слайдере 6 карточек-направлений вместо 5 (логика бесконечной прокрутки не зависит от количества).

## Открытые вопросы / следующие шаги
- Слайдер на ≤640px: смещение трека заменено с `-18vw` на `+28vw` — активная карточка центрируется (учтён масштаб `.back-stack` 1.30 в конце сцены, который сдвигает левый край слоя на ≈-19vw).
- Папка проекта называется `inwaytour ` с пробелом в конце — при деплое/скриптах лучше переименовать.
- Заменить сценовые изображения Мостара на свои.
- Переключатель языка (RU) — заглушка, без логики.
- Соцсети на старом сайте вели на «#» — не добавлены.
